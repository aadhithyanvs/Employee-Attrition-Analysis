# Employee Attrition Analysis

## Project Overview
This project analyses employee data to understand employee attrition and identify factors that influence employees leaving an organization.

## Dataset
- Dataset: IBM HR Analytics Employee Attrition
- Total Records: 1470
- Total Columns: 35

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook
- Git and GitHub

## Initial Data Inspection
- Rows: 1470
- Columns: 35
- Missing Values: 0
- Duplicate Records: 0

## Business Questions
1. Which department has the highest employee attrition?
2. Does monthly income affect employee attrition?
3. Which age group has the highest employee attrition?
4. Does overtime affect employee attrition?
5. Which job role has the highest average monthly income?
